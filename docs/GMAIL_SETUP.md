## Один раз в Google

1. Открыть [Gmail API в существующем проекте](https://console.cloud.google.com/apis/library/gmail.googleapis.com?project=open-claw-agent-487913) и включить API, если он ещё не включён. Если у аккаунта нет доступа к этому проекту, использовать свой Google Cloud проект.
2. В Google Auth Platform настроить Branding (например, `OtpremaOps local`), Audience **External** для личного Gmail. В режиме Testing добавить `koallalenivaa@gmail.com` как test user. Запрашиваемые права: `openid`, `https://www.googleapis.com/auth/userinfo.email`, `https://www.googleapis.com/auth/gmail.send`. Календарь, Drive и чтение Gmail API не запрашиваются; чтение выполняет IMAP.
3. В [Clients](https://console.cloud.google.com/auth/clients?project=open-claw-agent-487913) нажать **Create client → Desktop app**, скачать JSON. Не выбирать Service account или Web application. Создание клиента и принятие условий выполняет владелец Google-аккаунта; агент не принимает условия от его имени.
4. Открыть `E:\open-claw-agent\connect_otpremaops_gmail_api.cmd`, выбрать скачанный JSON и разрешить доступ в браузере именно для `koallalenivaa@gmail.com`. Окно не спрашивает пароль приложения. Другой Google-аккаунт будет отклонён.

Содержимое JSON, пароли, коды и токены **не отправлять в чат**. Вместо выбора файла можно сохранить JSON локально как `H:\serbiya\outreach\gmail_oauth_client.json`; файл исключён из git. Токены сохраняются только зашифрованными в `gmail_oauth.dpapi` от текущего Windows-пользователя.

После успешной авторизации CMD запускает обычный цикл кампании. Планировщик продолжает работу каждые четыре часа. Ночью первые письма не отправляются: действует окно 09:00–17:00 по Белграду в будни. Лимит — одно письмо за цикл, до пяти в день. Пробного письма при авторизации нет; `sent` означает принятие Gmail API, а не доставку или прочтение.

В режиме Google **External / Testing** разрешение с Gmail scope обычно требует повторного входа через семь дней. Это не постоянное подключение; для длительной работы выбрать подходящий статус приложения согласно правилам Google, не отключая проверки. При отзыве/истечении доступа агент блокирует исходящие, сохраняя чтение IMAP и журнал попыток.

Основание: [официальная настройка Desktop OAuth](https://developers.google.com/workspace/gmail/api/quickstart/python), [правила OAuth и срока refresh token](https://developers.google.com/identity/protocols/oauth2), [отправка Gmail API](https://developers.google.com/workspace/gmail/api/guides/sending).
