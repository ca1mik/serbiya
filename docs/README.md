- [PROSPECTS_WAVE3_2026-09-29.md](PROSPECTS_WAVE3_2026-09-29.md), [WAVE3_INDEX.md](../outreach/WAVE3_INDEX.md) и [отчёт третьей партии](../outreach/WAVE3_SEND_REPORT_2026-09-29.md) — ещё 20 новых компаний, отдельно подтверждённых владельцем; **отправка началась и продолжается фоновой задачей**. Живой счётчик: [статус партии](../outreach/approved_batch_wave3_2026-09-29_status.json). CRM 46 компаний / 49 строк. Общие ограничения Gmail и VPN сохранены.

OAuth/IMAP подключены, API включён. Обе партии (6 + 20) приняты Gmail по двум отдельным подтверждениям согласия со слов пользователя, без повторов. Будущие контакты текущими аттестациями не охвачены.

Это исследование и материалы для согласования. Прежним 26 компаниям отправлено по одному первому письму; третья двадцатка выполняется отдельно, считать отправленное только по журналу/статусу партии. Ответы и спрос пока не подтверждены. Цены в КП — коммерческая гипотеза. Продукт работает только с имитацией государственной системы; приём Gmail не доказывает доставку во входящие или прочтение.

В коде доработан многопозиционный импорт с отклонением конфликтного документа целиком, тесты отделены от базы приложения и обработаны фоновые ошибки PostgreSQL без печати параметров подключения. Проверено: 30 unit/integration-тестов, TypeScript, ESLint и production-сборка. Браузерные e2e не выполнены из-за ограничения запуска сервера в среде. Детали и оставшийся временный каталог проверки — в TECHNICAL_PLAN.md.
